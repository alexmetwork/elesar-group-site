# Новый сайт Элесар-Групп

Прототип сайта elesar-group.ru. Разрабатывается параллельно с действующим сайтом.

## Запуск

Открыть `index.html` в браузере. Внешние зависимости и сборка не нужны.

## Что работает

- Главная и пять направлений поставок.
- Склад: 1276 позиций из выгрузки на 18.11.2026; поиск, фильтры, пагинация, карточки.
- Производители, пример посадочной Analog Devices.
- Форма подбора ВЧ-кабельной сборки с переносом требований в обращение.
- Выбор файла BOM и ввод спецификации текстом.
- Просмотр состава заявки без отправки.

## Ограничения

Внешние API, разбор Excel, почта, учёт согласий, аналитика не подключены.
BOM не отправляется на сервер. Контактные данные из форм не сохраняются.
Хеш-навигация выбрана только для прототипа. Для рабочего сайта нужны отдельные индексируемые страницы, метаданные, sitemap и перенаправления старых адресов.
Стек рабочего сайта не утверждён. Текущий HTML не закрепляет выбор архитектуры.
Использован оригинальный словесный логотип из предоставленной презентации. Montserrat 500/600/700 с кириллицей размещён локально с лицензией OFL; основной интерфейс использует системный Segoe UI с запасным Arial.

## GitHub Pages

После создания репозитория и загрузки файлов: Settings > Pages > Source: GitHub Actions.
Workflow `.github/workflows/pages.yml` запускается вручную через Actions после настройки Pages и публикует статический прототип без привязки домена elesar-group.ru.
Для приватного репозитория доступность Pages зависит от тарифа GitHub; репозиторий не следует делать публичным без отдельного решения владельца.
Тестовый сайт просит поисковиков не индексировать его. Это не ограничение доступа.
Публиковать реальные формы и персональные данные только после реализации серверной обработки и согласий.
