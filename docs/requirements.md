# Требования и рабочие решения

## Цели

1. Визитка для посетителя после встречи/письма.
2. Привлечение заявок из обычного и ИИ-поиска.
3. Полезные проверяемые материалы, на которые могут ссылаться ИИ-сервисы.
4. Поиск по собственному складу, перспективно по внешним источникам, обращение по BOM.

## Аудитория

Закупщики и инженеры-разработчики производственных компаний. Работа с юридическими лицами. Образцы - для оценки и внедрения в серию, возможны бесплатно по согласованию.
Проектные поставки формируют основную часть бизнеса.

## Приоритеты продукции

1. PCB-компоненты: ADI, Texas Instruments, AMD/Xilinx и другие.
2. Соединители и кабельные сборки всех типов.
3. ВЧ/РЧ и измерительное оборудование: Keysight, Rohde & Schwarz и другие.
4. Камеры, OEM, оптика, матрицы, вычислительные модули, стабилизация, лидары, тепловизионные решения, радиосвязь, видеопередача.
5. Серверы, GPU, SSD, память и прочие вычислительные компоненты.
По новым направлениям есть специалист, готовый предметно отвечать на запросы.

## Позиционирование

Сложные запросы, инженерный подбор, квалификация поставщиков, соответствие решения задаче.
Не обещаем лучшие цены и короткую поставку 2-3 недели как универсальное преимущество.
Статус представительства/производства подтверждаем перед публикацией. Соединители/сборки могут предлагаться в собственных обозначениях, с подбором известных брендов.

## Склад

Исходник: Excel от пользователя, 1276 позиций на 18.11.2026.
Публикация всех данных разрешена. Цены с НДС, свободные остатки, минимальная отгрузка.
Обновление: Алекс присылает новую выгрузку несколько раз в месяц.
Единицы измерения и нормализация категорий требуют доработки.
Вопросы маркировки отдельных товаров уточняются перед реальными отгрузками; в прототипе нет утверждений о её наличии.

## Поиск и обращения

Собственный склад - полная доступная информация.
Внешние источники (Китай, DigiKey, Mouser) - объём выдачи зависит от доступного API и условий использования. API пока не проверены и не подключены; название источника и коммерческие правила не утверждены.
Корзины и оплаты на сайте нет. Условия согласуются по email/мессенджеру.
Заявки должны попадать на info@elesar-group.ru.
Нужен учёт согласий и обработка персональных данных; механизм, тексты и сроки хранения ещё не выбраны.

## ВЧ-конструктор

Первый сценарий только для ВЧ-кабельных сборок.
Концы А/Б, кабель, длина, частота, КСВ, сопротивление, количество, дополнительные условия.
Результат - требования к запросу. Подтверждение совместимости/цены инженером, автоматической гарантии нет.
