# Дизайн

## Источник
Брендбук Элесар CMYK, предоставлен 23.11.2026. Шрифты и цвета проверены визуально по страницам 13-14 PDF.

## Решения и предпочтения

- Предпочтительный фирменный акцент пользователя: #3E89DD.
- Дополнительный тёмно-синий для сайта: #102A43. Это предложение для сайта, не цвет из брендбука.
- Тёмные главные экраны в сочетании со светлыми страницами каталога.
- В брендбуке: Montserrat Bold/Medium для заголовков; Arimo Regular для основного текста.
- Пользователь предпочитает Segoe UI. Предлагаем Montserrat в заголовках и Segoe UI в основном тексте/интерфейсе. Сочетание ещё предстоит оценить визуально.
- Текущая версия использует системный Segoe UI с запасным Arial. Montserrat пока не подключён.
- Логотип брать оригинальный; не перерисовывать. Брендбук содержит растровые страницы, отдельный SVG/PNG предпочтителен для сайта.
- На фирменном #3E89DD небольшие белые надписи требуют проверки контраста; для кнопок используем более тёмный #2768B0.
- В брендбуке также #2DABE3, #3F3F3F, #E8E8E8.

## Для следующей итерации

Оригинальный логотип; подключение шрифтов; просмотр на телефоне; финальные тексты и фотографии продукции; доступность интерактивных элементов.
